# 📄 AI Resume Analyzer

An AI-powered resume analysis application that evaluates resumes and provides useful feedback to help candidates improve their resumes.

## 🚀 Features

- Resume analysis
- Skills identification
- Strength identification
- Improvement suggestions
- AI-generated feedback
- Resume quality assessment
- User-friendly interface
- FastAPI backend
- HTML, CSS and JavaScript frontend
- OpenRouter API integration

## 🛠️ Tech Stack

- Python 3.14
- FastAPI
- HTML5
- CSS3
- JavaScript
- OpenRouter API
- LLM
